Food Agent

A full-stack app that turns a plain-language request into nearby restaurant recommendations.

Type
Full-stack web application
Field
Recommendations
Data
Google Places API
Tools
Next.js, FastAPI

Problem

People describe what they want in plain language, such as a cheap breakfast open now within 2 miles. Rigid filter forms handle that poorly.

What I built

A geo-aware recommendation system with a Next.js front end and a FastAPI back end. It parses natural-language queries and ranks nearby options by distance using the Haversine formula, with data from the Google Places API.

Outcome

Nearby restaurants are returned in real time with ratings, distance, open or closed status, and direct Google Maps links.
